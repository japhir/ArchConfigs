what is it? is it actionable?
   no
     → trash → dd
     → tickler → change status to ~TICK~, C-c C-s SCHEDULE
     → someday/maybe → change status to ~SOME~, refile to project or [[file:someday.org]]
     → reference -> org-roam-refile to today's daily note
   yes → what's the next action? <2m? do it now
   *delegate*? -> email/ask someone, then change status to ~WAIT~
   *defer*? -> C-c C-s SCHEDULE for some future date
   if it's a *next action*:
    → rephrase headline: verb, no reference to "it/this"
    → t n on heading to change status to ~NEXT~
    → C-c C-w refile
   if it's a *project*:
     → what's the desired outcome?
     → add ~[/]~ to beginning of line and C-c C-c on it to make it track the tasks
     → C-c C-c j on heading to add :prj: tag
     → C-c C-x p set CATEGORY property (for nice agenda)
     → if desired: C-c l to org-store-link, which adds an org-ID making it an org-roam node
