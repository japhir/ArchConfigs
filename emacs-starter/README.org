#+title: emacs-starter: a small Emacs for our shared org todo system

A standalone Emacs configuration for someone who uses Emacs as the desktop
client of a shared org-mode todo system (phones: orgzly-revived and beorg;
sync: WebDAV via the Nextcloud desktop client). Independent of =myinit.org=.
Windows is the target; it also loads on Linux for testing.

| File             | Role                                                         |
|------------------+--------------------------------------------------------------|
| =init.el=        | bootstrap: tangle+load =config.org=, plus =my/update-config= |
| =config.org=     | the configuration, literate; the only file to edit           |
| =welcome.org=    | the lessons, opened at startup until dismissed               |
| =cheatsheet.org= | one page of keys; =cheatsheet.html= is its printable export  |
| =emacs-open.cmd= | Explorer "Open with" target: routes to emacsclient/runemacs  |
| =emacs-org.reg=  | optional: gives =.org= files an Emacs icon                   |

* Setting up her Windows machine
1. Install Emacs 30: in PowerShell, =winget install GNU.Emacs=. Done when
   "Emacs" appears in the Start menu.
2. Install the Nextcloud desktop client from nextcloud.com/install and log in
   to the WebDAV account. In the wizard click "Skip folders configuration":
   its free-space check counts the whole account, not the folders you tick,
   and blocks on a small disk. Then in the client's settings use "Add Folder
   Sync Connection" twice: remote =iljline= to local
   =C:\Users\<name>\Nextcloud\iljline=, and her own folder likewise. Leave
   "virtual files" off: Emacs opens every file for the agenda and needs them
   on disk, also offline. Done when both folders show their =.org= files in
   Explorer.
3. Copy this directory's contents (not the directory) into
   =C:\Users\<name>\AppData\Roaming\.emacs.d\=. Create the folder if missing.
   Paste =%APPDATA%\.emacs.d= in the Explorer address bar to get there.
4. Open =config.org= and check the heading "where our files live": the sync
   root and both folder names must match what step 2 created.
5. Start Emacs. The first start downloads packages (a few minutes, internet
   needed); ignore compile warnings. Done when =welcome.org= is showing and
   =C-c d= opens an agenda listing tasks from both folders.
6. Print =cheatsheet.html= from a browser.

Keys are documented in =cheatsheet.org=; the tables in =config.org= (top) and
=welcome.org= repeat it. A rebind is an edit in all three, then the export
below.

Regenerate the HTML after editing the cheatsheet:
#+begin_src sh
  emacs --batch cheatsheet.org -f org-html-export-to-html
#+end_src

* Opening .org files from Explorer
=emacs-open.cmd= is part of the starter and already sits in =.emacs.d= from
step 3 above; if it is missing, copy it in. If Emacs is installed somewhere
other than =C:\Program Files\Emacs\emacs-31.1\bin=, edit the =BIN= line at
the top of the file to match.

To make Explorer use it: right-click an =.org= file, "Open with", "Choose
another app", "Look for another app on this PC", pick =emacs-open.cmd=, and
tick "Always use this app". A console window flashes briefly when it runs;
that is harmless.

Why not point Explorer straight at =emacsclient.exe -a runemacs=: emacsclient
does not quote its =-a= alternate-editor argument, so the space in "Program
Files" breaks the command. =emacs-open.cmd= sidesteps this by trying
=emacsclient= first and falling back to =runemacs= with =||= instead.

Optional: giving =.org= files the Emacs icon instead of the generic one.
Explorer ignores an icon attached to a batch-file application, so the
association has to go through a registered file type instead. =emacs-org.reg=
registers "Org file (Emacs)" with the Emacs icon and =emacs-open.cmd= as its
open command, and makes it the default for =.org=. Per-user, no admin.

1. Get =emacs-org.reg= into =.emacs.d= (it comes along with
   =M-x my/update-config=, or copy it by hand). Open it in Notepad, replace
   =<USER>= with her Windows username (the folder name under =C:\Users\=),
   fix the Emacs path if needed, keep the doubled backslashes. Save with
   "Opslaan als", type "Alle bestanden (*.*)", name in quotes:
   ="emacs-org.reg"=, otherwise Notepad appends =.txt=.
2. Double-click it, accept the "are you sure" prompt.
3. Windows still remembers the "Open with" choice from above, which
   overrides the new type. In regedit, go to
   =HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Explorer\FileExts\.org=,
   right-click the =UserChoice= key under it, Verwijderen. Windows blocks
   editing inside that key but allows deleting it.
4. Sign out and in. The icon changes; double-click an =.org= file once to
   confirm it still opens in Emacs. If Windows asks how to open it, pick
   "Org file (Emacs)" and tick Always.

* Updating her config
=my/update-config= (defined in =init.el=, so it works even if =config.org=
is broken) re-downloads every starter file from GitHub. The flow:

1. Edit and push from here (this repo), as normal.
2. On her machine: =M-x my/update-config=, then restart Emacs.
3. Each file's previous copy is kept alongside it as =<file>.bak= before the
   new one is fetched, so nothing is lost if a download fails or the new
   version is wrong.
4. If a new =config.org= fails to load, Emacs still starts: =init.el= is the
   bootstrap and does not depend on =config.org= loading successfully. Fix
   the problem, push again, and have her run =my/update-config= again.

* If something fails on first start
- Only a warning about a lexical-binding cookie in =~/.emacs=, and no
  welcome file: a stray =.emacs= in =%APPDATA%= is being loaded instead of
  =.emacs.d\init.el= (Emacs takes the first of =~/.emacs=, =~/.emacs.el=,
  =~/.emacs.d/init.el=). =C-h v user-init-file= shows which file won. If
  the stray one is empty, delete it and restart.

- "The directory ~/.emacs.d/server is unsafe": the =server= folder under
  =.emacs.d= is owned by another account (typically after copying as
  administrator). Right-click it, Properties, Security, Advanced, change the
  owner to her user. Until then Emacs still starts; only the
  second-instance-reuses-the-first behaviour is off.
- A warning "Org folder not found": a name under "where our files live" in
  =config.org= does not match a folder under =Nextcloud=, or the sync client
  has not created it yet. The agenda works with whatever folders exist.

* Reusing this for another household
Names are literal in =config.org=, on purpose. Search and replace, in this
order: =inbox-iljline.org= (shared inbox file), =iljline= (shared folder),
then the two names in the "who is who" block, =line= and =ilja=, and the
personal folder name =line= under "where our files live". The =DONE-<NAME>=
keywords, tags and =CREATED_BY= follow from the two variables. Then set the
same keyword set in every other client that edits the shared files.

* Optional: Dutch spell checking
Needs the =hunspell= program and an =nl_NL= dictionary on PATH. One way, in
PowerShell: install Scoop (scoop.sh), then =scoop install hunspell=, then put
=nl_NL.aff= and =nl_NL.dic= (from the LibreOffice Dutch dictionary extension,
or OpenTaal) into Scoop's hunspell =share\hunspell= folder. Done when
=hunspell -D= lists =nl_NL=. Restart Emacs; misspelled words in org files get
underlined.

* Testing on Linux
=my/sync-root= falls back to =$HOME/Nextcloud= when =USERPROFILE= is unset.
Point =HOME= at a scratch tree with dummy org files and start Emacs with its
own init directory:
#+begin_src sh
  HOME=/tmp/starter-test emacs --init-directory /tmp/starter-test/.emacs.d
#+end_src

* Design notes
- Two variables, =my/me= and =my/partner=, derive the =DONE-<NAME>= keywords,
  the person tags, =CREATED_BY=, and the agenda filter. Swap them and the
  same file is Ilja's side.
- The literate file is =config.org=, not =init.org=: =org-babel-load-file=
  tangles to a =.el= of the same name, and =init.el= is the bootstrap.
- Per-person =DONE= states exist because neither phone app can run a hook on
  state change; a keyword is the only cross-app way to record who finished
  a task.
- Lock files off, backups and autosaves local, auto-revert on: the synced
  folders must contain only what the phones can read.
