* One-off elisp migration helpers (USER runs against ~/org)
Not config — analysis/assist scripts for the data-side backlog. Scaffolds

** Project audit — empty / multi-NEXT projects
Targets: "lots of stale projects with 0 tasks" and "multiple NEXT → demote".
#+begin_src emacs-lisp
  (defun my/gtd-project-audit ()
    "Report :prj: headings that are EMPTY (0 actions) or have >1 NEXT."
    (interactive)
    (require 'cl-lib)
    (let (report)
      (org-map-entries
       (lambda ()
         (when (member "prj" (org-get-tags nil t)) ;; local tags only
           (let ((heading (org-get-heading t t t t))
                 (file (file-name-nondirectory (buffer-file-name)))
                 (next 0) (parked 0) (checks 0))
             (save-restriction
               (org-narrow-to-subtree)
               (org-map-entries
                (lambda ()
                  (pcase (org-get-todo-state)
                    ("NEXT" (cl-incf next))
                    ("TODO" (cl-incf parked))))
                t 'tree)
               (goto-char (point-min))
               (while (re-search-forward "^[ \t]*[-+*] \\[[ X-]\\]" nil t)
                 (cl-incf checks)))
             (let (flags)
               (when (and (zerop next) (zerop parked) (zerop checks))
                 (push "EMPTY" flags))
               (when (> next 1) (push (format "%d-NEXT" next) flags))
               (when flags
                 (push (format "%-12s %s  [%s]" file heading
                               (string-join flags ","))
                       report))))))
       nil 'agenda)
      (with-current-buffer (get-buffer-create "*GTD project audit*")
        (erase-buffer)
        (insert "Projects needing attention (EMPTY = stale 0-task; N-NEXT = demote extras to TODO)\n\n")
        (insert (string-join (nreverse report) "\n"))
        (goto-char (point-min))
        (display-buffer (current-buffer)))))
#+end_src
Caveat: the inner map counts the =:prj:= heading itself, so a checklist-model
project (heading carries =NEXT=) reads as =next>=1= → not EMPTY. Tune if you
want to ignore the heading's own keyword.

** Keyword-less project children — candidates to set TODO
#+begin_src emacs-lisp
  (defun my/gtd-keywordless-project-children ()
    "List sub-headings under a :prj: that carry NO todo keyword (candidate TODO)."
    (interactive)
    (let (report)
      (org-map-entries
       (lambda ()
         (when (member "prj" (org-get-tags nil t))
           (let ((proj (org-get-heading t t t t)))
             (save-restriction
               (org-narrow-to-subtree)
               (org-map-entries
                (lambda ()
                  (unless (or (org-get-todo-state)
                              (= (org-current-level) 1)) ;; skip the prj heading
                    (push (format "%s  ->  %s" proj (org-get-heading t t t t))
                          report)))
                t 'tree)))))
       nil 'agenda)
      (with-current-buffer (get-buffer-create "*GTD keywordless children*")
        (erase-buffer)
        (insert "Project sub-headings with no keyword (decide: TODO? note? promote NEXT?)\n\n")
        (insert (string-join (nreverse report) "\n"))
        (display-buffer (current-buffer)))))
#+end_src
Caveat: some keyword-less children are legit notes, not actions — human review
required; this just surfaces candidates. The level-1 skip only works for
top-level projects; a =:prj:= nested deeper reports its own heading.

** CATEGORY audit — for the area migration (Phase 4, ADR 0002)
#+begin_src emacs-lisp
  (defun my/gtd-category-audit ()
    "List :prj: headings with a LOCAL CATEGORY property (project-name era).
  These need CATEGORY re-stamped to an area (or cleared)."
    (interactive)
    (let (report)
      (org-map-entries
       (lambda ()
         (when (member "prj" (org-get-tags nil t))
           (let ((cat (org-entry-get (point) "CATEGORY"))) ;; may include inherited
             (when cat
               (push (format "%-30s :CATEGORY: %s" (org-get-heading t t t t) cat)
                     report)))))
       nil 'agenda)
      (with-current-buffer (get-buffer-create "*GTD category audit*")
        (erase-buffer)
        (insert "Projects with a CATEGORY (review: keep area or restamp)\n\n")
        (insert (string-join (nreverse report) "\n"))
        (display-buffer (current-buffer)))))
#+end_src
Caveat: =org-entry-get ... "CATEGORY"= can return an inherited/file-level value;
to see only drawer-local values, parse the =:PROPERTIES:= drawer directly.
