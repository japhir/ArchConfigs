As-built snapshot of the GTD workflow implemented in the org-mode section of
=myinit.org=. Companion to [[file:CONTEXT.org][CONTEXT.org]] (the glossary) and [[file:docs/adr/][docs/adr/]] (the
decisions behind the shape). Reference doc — lives in the ArchConfigs repo,
deliberately /not/ under =~/org= (not an agenda file).

This file describes what is /live/ today. Decisions that are agreed but not yet
implemented are marked → ADR and listed under "Decided, pending implementation".

* The five phases
** Capture
- =C-c c= → org-capture; every template lands in =inbox.org=, =CREATED= auto-set
- Mobile (Orgzly) → =mobin.org=
- Web → org-protocol templates =p= / =L= into =inbox.org=
- =C-c n d= → org-roam daily note — log/journal only, never a task bucket (ADR 0003)
- =C-c c j= → journal datetree
- =inbox.org= + =mobin.org= carry =#+filetags: inbox= → =i= agenda catches both
- =C-c c s= → shared inbox =iljline/inbox-iljline.org=, =CREATED= + =CREATED_BY: ilja= set (ADR 0006)
- =C-c t= stamps =CREATED= on a hand-written heading; a heading's first todo
  keyword stamps it automatically

** Clarify
- Decision tree lives in =weekly_review.org=, run during the weekly review
- Actionable? <2 min do now; delegate→=WAIT=; defer→tickler; project→ =:prj:=
- Non-actionable: trash / =TICK= / =SOME= / reference→org-roam

** Organize
- TODO states: =TODO → NEXT → WAIT → TICK → SOME | DONE-ILJA DONE-LINE DONE CANC= (ADR 0001, 0005)
  - =TODO= = parked project action; =NEXT= = the one actionable now (exactly one per project)
  - =d= = =DONE-ILJA=, =D= = =DONE-LINE=, =f= = plain =DONE=; the shared keyword
    set, identical on Line's Emacs and both phones. Personal files get
    =DONE-ILJA= too; harmless.
  - Keyword faces come from the active Modus palette and follow circadian.
  - Anything that tests "done" uses =org-done-keywords= or =TODO={^DONE}=,
    never the literal =DONE= (=j= projects, stuck projects)
- Projects: =:prj:= heading + =[/]= cookie; identified by tag + outline path (ADR 0002)
- Areas of Responsibility: the headings tagged =:area:= in =life.org=
  (=org-areas-file=), any level, read live; carried on items via =:CATEGORY:=
  (ADR 0002, amended 2026-09-26). =C-c A= stamps one
  at clarify, and on a =:prj:= heading pushes it onto the whole subtree
- Contexts: =@=-tags — place / tool / energy / with-whom (=@agenda= + person); see CONTEXT.org.
  The kind-of-work tags (=@write @program @read @createplot @schedule=) and their
  =g*= agendas were removed 2026-09-26; items still carrying them are harmless
- Assignee (shared folder only): lowercase =ilja= / =line= tag, at most one,
  none = either of us (ADR 0006). Not the capitalised =:Line:= agenda-list tag.
- =SCHEDULED= = tickler ("resurface on this date") only; =DEADLINE= + =gcal.org= = hard landscape (ADR 0004)
- Files: =todo.org= (personal), =work.org= (work), =someday.org=, =lists.org=,
  =journal.org=, =life.org= (areas); reference → org-roam notes
- Shared folder =~/org/iljline/=: the only files Line and I both edit (ADR
  0007). Its =.org= files are refile targets so a captured task can be moved
  there at clarify (convenience, not an ADR requirement)
- Refile: =C-c C-w=; =C-c n r= / =C-c n R= refile a heading into a daily note (as a log entry)

** Reflect
- *Weekly review* (capture template =r= → =weekly_review.org=, clocked): get
  clear / get current / get creative. CANONICAL — mirrors the David Allen
  podcast steps exactly. ⚠️ FROZEN: do not edit =weekly_review.org=.
- *Daily pass* (capture template =d= → =daily_review.org=): the mid-week
  engine — empty =inbox.org= + =mobin.org=, sweep stray tasks out of
  =notes/daily/=, pick the day's =NEXT=s. Light; never duplicates the weekly.
- Agendas: =A= block, =n= next, =w= waiting, =j= projects, =I= important, =#= stuck
- =a= areas: one block of live projects per area, an area with none flagged
  NEGLECTED; the last block lists live projects whose =CATEGORY= is no area
  (the migration worklist, ADR 0002). Shadows org's built-in week agenda on =a=
- Agenda files: every =.org= under =~/org= except =notes/= (org-roam),
  rescanned before each agenda; =d= sweeps all of =notes/= for stray tasks
  (ADR 0003)
- Shared tasks tagged =line= only are hidden from every agenda
  (=org-agenda-skip-function-global=); =S= shows the whole shared folder for
  planning together

** Engage
- Context agendas =g*=, energy =E*=, people =p*=, =W= work / =P= personal
- org-pomodoro (=C-c p=) for focus blocks

* Constraints (do not "fix")
- =weekly_review.org= is frozen — its steps follow David Allen's published
  process deliberately. Do not consolidate it with the daily pass or
  "streamline" its steps.
